# Array Arena Profile-Informed Reference

This packet preserves the first human-approved result from the math creative
sandbox.

## Winning chain

```text
Grade 3 multiplication contract
+ a small factual Reina evidence packet
→ Claude Fable 5 creates the experience direction
→ Claude Opus 5 implements the direction once
→ human visual and interaction review
```

Human result: approved as the strongest direction from the experiment.

The profile changed the experience structurally rather than cosmetically:
Array Arena introduced a championship objective, opponents, a bracket,
escalating reasoning, bluff detection, recovery, and a visible payoff.

## Important boundary

Array Arena is a reference candidate, not a reusable template or required
Sunny mechanic. Future generation should preserve the successful process and
measured qualities, not force wrestling, arenas, brackets, or competition.

The child packet contains factual observations rather than inferred commands.
It does not say that Reina likes competition, require a wrestling theme, or
direct the model to reproduce a prior spelling activity.
