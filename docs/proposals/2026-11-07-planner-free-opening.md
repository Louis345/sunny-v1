# Proposed contract 54: the Planner chooses how a list begins

Status: **draft for owner approval** (2026-11-07). Not in effect until `LEARNING_FEEDBACK_LOOP.md` is amended.

## Why

A new spelling list currently opens with Discovery: every assigned word, hidden, in one sitting, before any teaching
or reward. Sunny already holds weeks of a child's history and a prior for every word before the first answer. In the
first session under the economy, the opening check was twelve hidden words in a row; the child asked for help three
times before the teaching board existed, and the session ended before its reward. The owner's direction: the Planner
should optimize for the child, break the work up so it is not a grind, and figure that out from her evidence, not
from fixed rules.

## What changes (teaching rules removed)

1. **No mandatory opening check.** "New spelling cycles offer every assigned spelling target in independent Discovery
   before targeted practice is planned" is removed. For each new list the Planner decides how to begin: check every
   word, check only the words it is unsure of, open with teaching and place short checks inside activities, or any
   mix. It may spread checks across stops so no stop feels like a test.
2. **No fixed board order.** The probe board is no longer required before a teaching board. The Planner may open
   with whatever board it judges best and decide later boards from evidence as today.
3. **No code gate on Quest or Boss.** The minimum-evidence gate before Quest is removed. The Planner decides when an
   encounter is justified, citing the evidence it used.
4. **Help is always available.** If the child asks for help on any word, the companion helps. That answer is then
   recorded as assisted, exactly as it happened.

## What stays (record-keeping, not rules)

These do not limit any choice; they keep the record true so the Planner learns from reality:

- Every answer is recorded as it happened: independent, assisted, or practice. Code never upgrades one into another.
- A word with no independent answer is **unknown**, never counted as known or mastered.
- A word taught before it was ever checked is marked **seen before baseline**, so a later correct answer is not
  counted as learning gain.
- Graded school results remain the final check of every prediction.
- Each Planner decision records its reasons and the evidence it cited, so later results can show whether it worked.

## How we will know it works

Per list, compared with lists started the old way: graded test score, independent accuracy at Quest and Boss, time
to the first reward, help requests, sessions that reach the end-of-board call, and the child's own rating. If a
freer opening costs accuracy, the evidence will show it and the Planner will see it too.
