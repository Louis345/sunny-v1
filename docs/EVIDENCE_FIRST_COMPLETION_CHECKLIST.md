## Human-caught defect carried into this work

A person sees those cues immediately; ordinary practice tests deliberately expected them, and logs did not establish independent assessment eligibility. The new assessment invariant must prove hidden spelling, unconstrained first response, no correctness feedback, accurate visibility telemetry, and no legacy practice-evidence write.
